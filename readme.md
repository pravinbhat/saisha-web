# Saisha Technologies website

Public static marketing website for Saisha Technologies.

- **Production URL**: https://www.saishatech.in / https://saishatech.in
- **Tech Stack**: Vite, semantic HTML, vanilla JavaScript and CSS
- **Hosting**: Vercel

## Local Development

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
# App runs at the URL printed by Vite
```

## Production Build

```bash
npm run build
npm run preview
```


The Vercel project can use the default Vite settings: `npm run build` as the build command and `dist` as the output directory. Update the contact address in `index.html` when the production inbox is ready.
